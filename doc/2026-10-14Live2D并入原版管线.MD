# Live2D 并入原版管线方案（消灭行为分叉）

> 按 plan-template-enhanced 模板编制。方案确认后执行。
> 前置：防闪烁修复已推送（f2a45f8）；复刻版清理已提交（b3b0da5，push 补推待网络）。

## 一、修改目标

- **问题描述**：Live2D 与 Spine 行为分叉——live2d-stage.js 自建了一套平行实现（自创右栏紫色区块：缩放滑杆/重置/±/动作下拉/表情下拉 + 自建渲染循环 + 自己的指针事件），导致：
  ① 右栏出现两套动作列表（原版「动作」区显示的还是上一个 Spine 模型的 idle/motion，自创区又一个 L2D 动作下拉）；
  ② 原版 Spine 支持的双指触屏缩放，Live2D 没有（覆盖层 canvas 只实现了单指拖拽 + 滚轮，没实现 pinch）。
- **期望效果**：Live2D 模型走**原版同一管线**——右栏「动作/皮肤/播放/缩放」等原版控件直接对 Live2D 生效；双指缩放、滚轮缩放、拖拽行为与 Spine 完全一致；自创紫色区块删除。
- **成功标准**：
  1. 点 Live2D 模型后，右栏原版「动作」区显示的是**该 L2D 模型的 motions**（不再是上一个 Spine 模型的），点击即切换；
  2. 双指触屏缩放 Live2D 生效（与 Spine 手感一致）；
  3. `live2d-sidebar-section`（自创区块）从 DOM 消失；
  4. Spine 全功能回归不变。

## 二、潜在问题分析

| 风险类型 | 可能性 | 影响 | 缓解措施 |
|----------|--------|------|----------|
| 兼容性破坏 | 高 | 原版 bundle 的渲染循环/控件是压缩代码，直接改它违背「baseline 逐字节等价」约束 | **不改 bundle**。在补丁层做「L2D 适配器」：把 L2D 模型包装成 store.currentModel 兼容的形状 + 拦截原版控件事件 |
| 原版控件事件被 React 接管 | 高 | 原版「动作」按钮的 onClick 在 React 闭包里，补丁层加 listener 会双触发或无效 | 用**事件捕获阶段拦截**（capture:true + stopPropagation），把 L2D 动作切换截胡 |
| 动作列表内容对不上 | 中 | 原版动作列表是 React 按 store.currentModel.animations 渲染的（L2D 时还是旧 Spine 的） | 切到 L2D 时用 `store.setState` 塞一份「L2D 伪装模型对象」（animations 数组格式对齐原版），React 会自己重渲染列表 |
| 双指缩放来源未知 | 中 | 原版 Spine 双指缩放的实现点还没定位到（bundle 无 touches.length>=2、无指针集合模式）→ 可能是 ctrl+wheel（浏览器把触屏双指转成 ctrl+wheel） | Step 1 先实测定位；L2D 侧无论来源是什么，同一事件源同步实现 |
| 皮肤/播放对 L2D 无意义 | 低 | L2D 无皮肤概念、播放控制语义不同 | 伪装对象里 animations/mappings 按语义映射；皮肤区对 L2D 置空 |
| 性能退化 | 低 | 适配器只是事件转发，不加渲染开销 | 无 |

**边界条件检查**：
1. L2D 未加载完就点原版动作按钮 → 适配器判 st.model 空，忽略；
2. Spine ↔ L2D 快速来回切 → 适配器按当前激活态路由事件（isActive 判断），防串台；
3. 原版控件 React 重渲染重绑事件 → 现有 MutationObserver 补回机制沿用，拦截器挂在容器级（不绑具体按钮）。

## 五、逐文件改动详情

### 5.1 `public/l2d-adapter.js`（新增，核心）

1. **伪装模型**：切到 L2D 时，把 `store.setState({ currentModel: { ...l2dMeta, animations: [{name:'complete'},...], skins: [], kind:'live2d' } })` → 原版 React 按新 animations 渲染动作列表（badge 同步正确）；
2. **事件拦截**：右栏容器 `capture` 阶段监听 click——若 `L2D active` 且点击目标是动作/播放/重置等按钮，`stopPropagation` + 调 `__LIVE2D_STAGE__.setMotion(name)` 等编程接口；
3. **动作名映射**：原版动作按钮文本（`complete / complete.motion3`）→ L2D motion group+index（live2d-stage 已有映射逻辑，抽成可调用）。

### 5.2 `public/live2d-stage.js`（大改）

- **删**：`buildSection/injectSection/hideSection/MutationObserver` 整段自创 UI（约 -90 行）；
- **留**：渲染循环、运行时懒加载、几何裁剪、showSeq、模型生命周期；
- **加**：编程接口 `setMotion(group, idx) / setExpression(i) / setZoom(v) / resetView()`（现内部函数提升导出）；
- **加**：双指 pinch——canvas 上 pointerdown/move 维护活动指针 Map，两指时算距离比缩放（与 Spine 的滚轮缩放同一 `st.model.scale` 通道与手感系数 1.1），并同步原版 fitMode 显示。

### 5.3 `server.mjs`

注入清单：`<script src="/l2d-adapter.js">` 加在 live2d-stage.js 之后（依赖其导出）。
