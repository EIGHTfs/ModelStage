# 主站刷新闪烁修复方案（去原版首屏残留）

> 按 plan-template-enhanced 模板编制。**方案确认后执行**（不主动改代码）。
> 复刻版（8804/rebuild）实验中止，改在原版主站 8803 上解决用户报告的问题。

## 一、修改目标

- **问题描述**：主站刷新时，有一瞬间可见原版 原版 的空状态欢迎页（居中「Spine 骨骼动画预览器」说明文字）与原版左侧模型库面板，随后才被本项目脚本隐藏。
- **期望效果**：刷新全程不出现原版左栏与欢迎文字（首帧即本项目形态：模型/空态都由本项目控制）。
- **成功标准**：硬刷新（Ctrl+F5）后 1 秒内连续截图 5 张，无一张出现原版左栏或欢迎文字；模型装载、角色树、Live2D 全部回归正常。

## 二、潜在问题分析

| 风险类型 | 可能性 | 影响 | 缓解措施 |
|----------|--------|------|----------|
| 兼容性破坏 | 中 | 原版 React 依赖左栏 DOM 复用（char-tree 复用其 [data-mid] 触发加载）；改 CSS 藏得太早/太狠可能挡住 React 初始化 | 只做「视觉隐藏」（display:none），DOM 保留；React 对不可见元素照常渲染 |
| 性能退化 | 低 | CSS 提前注入不增加运行时开销 | 无 |
| 安全漏洞 | 低 | 无 | 无 |
| 数据丢失 | 低 | 不动数据 | 无 |
| 防闪烁不彻底 | 中 | 原版 bundle 内联在 HTML 里，React 挂载可能早于 body 末尾补丁脚本执行——CSS 注入在补丁里就会晚 | 把防闪烁 CSS 放进 **HTML `<head>`**（server.mjs 注入逻辑，比补丁脚本更早，React 首次渲染前就生效） |

**边界条件检查**：
1. 左栏 DOM 仍需可点击（display:none 的元素 el.click() 照常派发，主站已在用，无回归）；
2. 若 React 更新左栏 class（版本变化）选择器失效 → 用双选择器兜底（class + 结构位置）；
3. 欢迎页是条件渲染（`C.length===0`），首屏必然出现 → 只能用 CSS 盖掉，不能删源码（baseline 逐字节约束）。

## 五、逐文件改动详情

### 5.1 `server.mjs`（核心，仅注入逻辑加一段 CSS）

- **当前位置**：`/index.html` 特例处理（约 L1368-1400），已有两处注入（store hook + 5 个补丁脚本标签）。
- **改动**：在这段里对 `patched` 再加一步——把下面 CSS 注入 `</head>` 前：

```css
/* 防首屏闪烁：原版左栏与空状态欢迎页由 React 挂载后渲染，
   本项目补丁脚本（body 末尾）运行晚于挂载，运行时再藏会闪现。
   此 CSS 在 head 中先行生效，React 首帧即隐藏。补丁脚本后续接管
   （左栏仍保留 DOM 供 [data-mid] 复用点击）。 */
.bv-sidebar.left-0 { display: none !important; }
.absolute.inset-0.pointer-events-none.z-10 > div.max-w-md,
div.absolute.inset-0.items-center.justify-center.pointer-events-none.z-10 {
  display: none !important;
}
```

（欢迎页选择器以源码实测的容器 class 为准：`absolute inset-0 flex items-center justify-center pointer-events-none z-10` + 子容器 `text-center px-6 max-w-md`——注入前用浏览器验证一次精确命中。）

- **原因**：原版 CSS 在 `<head>` 的 style 标签里，React 挂载后的首帧样式就生效；我们提前插入更高优先级规则，欢迎页/左栏从第一帧起就不可见。
- **影响**：仅影响 8803 的 `/` 响应；`file://` 直开 dist 不受影响（保持原版形态）；`tool/verify.mjs` 校验的是磁盘产物，不校验注入，无冲突。

### 5.2 `public/char-tree.js`（微调，可选）

### 5.3 `test/check-flash.mjs`（新增防回归）

- 无头 chrome `--screenshot` + `--virtual-time-budget=1500` 截首屏，检查像素/文本「Spine 骨骼动画预览器」与「模型库」是否出现；连续 3 次刷新取样。
