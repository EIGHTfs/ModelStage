# ModelStage 头像仓（独立私有仓）

角色头像的**唯一存放处**。主项目仓不存 png：只存 `config/index/*.index.json` 里每个角色的
`avatar` 文件名（见主仓 `docs/设计/名表.md` §四 与决策 D2）。

## 为什么单独一个仓

```
· 头像是二进制大文件（每个游戏上千张），放主仓会把仓吹大
· 每次换图都产生不可读的 diff，评审时淹没真正的代码改动
· 头像更新频率与代码不同，分开可以各自决定推送时机
```

## 目录结构

```
<游戏>/<角色ID>.png          角色头像（文件名与 index 里的 avatar 字段一致）
<游戏>/<角色ID>_<皮肤ID>.png  皮肤级头像（可选，本期不做）
<游戏>/manifest.json         <角色ID> → 文件名 的清单（由工具生成，不要手改）
tools/extract-avatars.mjs   提取工具（一次性，三条提取路）
```

`<游戏>` 取主仓 `config/index/<游戏>.index.json` 里的文件名前缀：
`azurlane` / `bd2` / `dcg`。

## 怎么加头像

```bash
# 1) 先看能提多少、缺多少（不写文件）
node tools/extract-avatars.mjs

# 2) 只刷新清单（从主仓 index 的 avatar 字段生成 manifest.json）
node tools/extract-avatars.mjs --manifest-only

# 3) 真拷（需要对应资源仓已在本机；会按 index 的 avatar 名落文件）
node tools/extract-avatars.mjs --write --game bd2
```

三条提取路（详见主仓 `docs/设计/名表.md` §四）：

```
① 资源目录自带 icon.png          → 首扫时拷入
② 仓内头像目录（icons.dir）      → 全量拷入并按 index 的 avatar 名重命名
③ 无源                           → 留空，界面用占位图兜底（不阻塞）
```

## 纪律

```
· 本仓只进 png 与清单 json，不混入任何代码（唯一例外是 tools/ 里的一次性提取工具）
· manifest.json 由工具生成；手工改 index 后重跑 --manifest-only 即可
· png 命名必须与主仓 index 的 avatar 字段逐字一致，否则界面找不到（表现为占位图）
· 本仓是**私有仓**：头像素材涉及第三方作品，不公开
```

## 部署位置

拉到本机固定位置后，主仓 `config/resources.json` 的头像根指向本仓根目录。
主仓 `.gitignore` 已忽略本目录 —— 它在主仓里是"看不见的"独立仓。
