# 设计 · 调试日志面板

> 浮在舞台右下角的日志浮层。设计目标：**信息密度够、任何位置展开都不出屏、尺寸只在一处定义**。
> 日志的采集与过滤语义见 `infra/log.js`；本文只讲界面形态。

---

## 一、两种形态

### 1.1 收起态（胶囊）

```
                                            ┌──────────────────┐
                                            │ ⓘ  日志  64  ⌃  │   ← 112 × 28，圆角 999
                                            └──────────────────┘
                                                      右下角，距视口右/下 16px
```

```html
<button class="dbg-pill">
  <svg class="dbg-pill-icon">…info…</svg>
  <span class="dbg-pill-text">日志</span>
  <span class="dbg-pill-count">64</span>
  <svg class="dbg-pill-chevron">…chevron-up…</svg>
</button>
```

### 1.2 展开态（两行标题栏）

```
┌────────────────────────────────────────────────┐  ← 宽 320（常量）
│ ⓘ 调试日志 64 条    ⬆上传  🗑清空        ⌃    │  ← 第 1 行：标题+计数 + 上传/清空 + 收起
├────────────────────────────────────────────────┤
│  ⌁调试  ⓘ信息  ⚠警告  ✕错误                  │  ← 第 2 行：四档按钮（横排）
├────────────────────────────────────────────────┤
│ 19:44:12.031  app  [MODEL.MOUNT] {"model…"}    │
│ 19:44:12.032  app  [STAGE] adaerbote_3 · …     │  ← 列表（可视高度由常量推出）
│ …                                              │
└────────────────────────────────────────────────┘
```

### 1.3 第 1 行：标题 + 计数 + 上传/清空 + 收起

```html
<div class="dbg-head">
  <div class="dbg-head-left">
    <svg class="dbg-head-icon">…info…</svg>
    <span class="dbg-title">调试日志</span>
    <span class="dbg-count">64 条</span>
  </div>
  <div class="dbg-head-acts">
    <button class="dbg-act"><svg>…upload…</svg><span>上传</span></button>
    <button class="dbg-act"><svg>…trash-2…</svg><span>清空</span></button>
  </div>
  <button class="dbg-collapse" title="收起日志面板" aria-label="收起日志面板">
    <svg>…chevron-down…</svg>
  </button>
</div>
```

**关键约束**：`dbg-head-left` 用 `flex:1; min-width:0`（可压缩），
`dbg-head-acts` 与 `dbg-collapse` 用 `flex:none`（不压缩）
⇒ **收起按钮永远不会被标题挤出去**。

### 1.4 第 2 行：四档按钮

```html
<div class="dbg-bar">
  <div class="dbg-levels" role="group" aria-label="日志级别">
    <button class="dbg-lv is-on" data-level="debug" aria-pressed="true">
      <svg class="dbg-lv-icon">…bug…</svg><span>调试</span>
    </button>
    <button class="dbg-lv is-on" data-level="info" aria-pressed="true">…</button>
    <button class="dbg-lv is-on" data-level="warn" aria-pressed="true">…</button>
    <button class="dbg-lv is-on" data-level="error" aria-pressed="true">…</button>
  </div>
</div>
```

```css
.dbg-lv {
  display: inline-flex; align-items: center; gap: 4px;
  height: 24px; padding: 0 8px;
  border: 1px solid var(--color-border);
  border-radius: 6px;
  background: transparent;
  color: var(--color-muted-foreground);
  font-size: 11px;
  transition: background 140ms ease, color 140ms ease, border-color 140ms ease;
}
/* 激活态与右栏控件同款：主色描边 + 主色淡底 + 主色字 */
.dbg-lv.is-on {
  border-color: var(--color-primary);
  background: color-mix(in srgb, var(--color-primary) 12%, transparent);
  color: var(--color-primary);
```

**默认态**：`debug` **关**，`info` / `warn` / `error` **开**。

**为什么四档用按钮不用下拉**：

```
下拉：只能选「某一档及以上」，想看「只看 warn + error」做不到
按钮：任意组合，且当前开了哪几档一眼可见
```

## 二、展开方向自适应

### 2.1 原则：面板永远朝视口中心展开，不写死方向

```
判断依据：胶囊（或面板当前位置）相对视口中心的象限

  ┌─────────────────┬─────────────────┐
  │  左上 → 向右下   │  右上 → 向左下   │
  ├─────────────────┼─────────────────┤
  │  左下 → 向右上   │  右下 → 向左上   │
  └─────────────────┴─────────────────┘

横轴：胶囊中心 x < 视口宽/2  ⇒ 面板左边缘对齐胶囊左边缘（向右长）
      胶囊中心 x ≥ 视口宽/2  ⇒ 面板右边缘对齐胶囊右边缘（向左长）
纵轴：胶囊中心 y < 视口高/2  ⇒ 面板上边缘对齐胶囊上边缘（向下长）
      胶囊中心 y ≥ 视口高/2  ⇒ 面板下边缘对齐胶囊下边缘（向上长）
```

**实现**：用 `left/top` 定位（不是 `right/bottom`），由方向算出具体值：

```js
const cx = pillRect.x + pillRect.width / 2;
const cy = pillRect.y + pillRect.height / 2;
const openLeft = cx >= innerWidth / 2;    // 靠右 ⇒ 向左长
const openUp   = cy >= innerHeight / 2;   // 靠下 ⇒ 向上长

// 锚点：胶囊的哪个角固定不动
const anchorX = openLeft ? pillRect.right : pillRect.left;
const anchorY = openUp   ? pillRect.bottom : pillRect.top;

panelLeft = openLeft ? anchorX - panelW : anchorX;
panelTop  = openUp   ? anchorY - panelH : anchorY;
```

**为什么必须这样**：面板 320×420，胶囊 112×28。胶囊在右下角时向下展开会直接出屏，
在左下角时向下也出屏 —— **写死一个方向必然有一半位置不可用**。

### 2.2 拖动边界按当前形态算，不按展开尺寸

```
❌ 错：拖胶囊时也按 320×420 夹取 ⇒ 胶囊只能在右上角一小块区域活动
✅ 对：拖拽时按当前可见形态的尺寸夹取
   · 收起态 → 用胶囊尺寸
   · 展开态 → 用面板尺寸
```

理由：展开时方向自适应，能从任意位置找到放得下的朝向，
所以**不需要「提前预留展开空间」** —— 那是用限制换安全，代价太大。

**唯一保留的约束**：胶囊本身必须完整在视口内（它是最小形态，缩无可缩）。

### 2.3 展开瞬间的越界兜底

方向自适应之后理论上不会出屏，但仍要兜底（极端情况：视口比面板还小）：

```js
panelLeft = Math.max(0, Math.min(panelLeft, innerWidth  - panelW));
panelTop  = Math.max(0, Math.min(panelTop,  innerHeight - panelH));
```

## 三、尺寸常量（只在一个地方定义）

```css
:root {
  /* 面板尺寸：改这里就够，别在别处写死 */
  --dbg-w: 320px;              /* 面板宽度 */
  --dbg-h: 420px;              /* 面板总高（含标题两行 + 列表） */
  --dbg-h-head: 36px;          /* 第 1 行高 */
  --dbg-h-bar: 34px;           /* 第 2 行高 */
  /* 列表可视高度 = --dbg-h − --dbg-h-head − --dbg-h-bar（自动算） */

  --dbg-row-pad: 6px 10px;
  --dbg-row-gap: 4px;

  --dbg-pill-h: 28px;
  --dbg-pill-offset: 16px;
}
```

```css
.dbg-shell {
  position: fixed; right: var(--dbg-pill-offset); bottom: var(--dbg-pill-offset);
  width: var(--dbg-w);
  height: var(--dbg-h);          /* 常量，不靠内容撑 */
  display: grid; grid-template-rows: var(--dbg-h-head) var(--dbg-h-bar) 1fr;
}
.dbg-list {
  min-height: 0;                 /* 关键：grid 子项要能缩 */
  overflow-y: auto;
  padding-bottom: var(--dbg-row-gap);
  scroll-behavior: auto;         /* 自动滚到底用 JS，不用 smooth（会拖慢） */
}
```

### 3.1 三条高度约束（血泪教训）

列表底部被裁掉过一个 34px 的角，原因是**两个高度源不一致**：外层容器写死 `max-height` 并带
`overflow:hidden`，而列表按另一套算出更大的高度 —— 列表底部永远不可见，
而滚动值本身完全正常（`scrollTop + clientHeight === scrollHeight`）。

```
① 高度只在一个地方定义（内层容器的 height: var(--dbg-h)）；外层容器不写死高度
② 外层容器不加 overflow: hidden（否则又在某处裁）
③ .dbg-list 必须 min-height: 0（grid 子项默认 min-height:auto 会撑破轨道）
```

**判断「是否被裁」必须往上找 overflow 祖先** —— 只比「列表 bottom vs 列表自己」会误判。

**动画落点**：高度动画放在内层的 `height`（`--dbg-h` ↔ `0`）。
外层只做 `overflow:hidden` 裁切 + 透明度/位移 —— 因为内层是固定高度，
外层若用 `grid-template-rows: 0fr` 是**压不下去**的（实测轨道仍算成完整高度）。

## 五、验收

| 项 | 判据 |
|---|---|
| **收起按钮可点** | 展开态下收起按钮的 `right ≤ 视口宽 - 8`，点击能收起 |
| **两行布局** | 第 1 行 = 标题+计数+**上传+清空**+收起；第 2 行 = **只有四档** |
| **四档是多选** | 4 个 `button`（不是 `select`），可任意组合开关 |
| **激活态** | 开启的档位有明显主色描边+淡底，与右栏控件一致 |
| **默认档位** | debug 关、info/warn/error 开 |
| **四档图标+文字** | 每个按钮都有图标 + 文字 |
| **上传/清空** | 图标 + 文字（不是纯图标），位置在**第 1 行** |
| **滚到底完整** | 滚到底后最后一条 `bottom ≤ 列表 bottom`，且能看到完整内容 |
| **高度常量生效** | 改 `--dbg-h` 面板高度跟着变；改 `--dbg-w` 宽度跟着变；两者互不影响 |
| **任意位置展开都不出屏** | 胶囊拖到四个角各展开一次，面板完整可见 |
| **无内联样式** | `grep 'style="' src/web/debug/` 无新增 |
| **五主题** | 四档激活态在五个主题下颜色都跟随 |
